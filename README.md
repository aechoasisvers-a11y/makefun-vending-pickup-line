A single pickup line spoken by a vending machine, flirting with a passing human using its own world of coils, buttons and exact change.

## Entry

> I don't have a heart, just coils, but they spin a little faster when you walk by. Press B7 and I'll drop something sweet. No exact change required.

## Run

```sh
python3 main.py
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
